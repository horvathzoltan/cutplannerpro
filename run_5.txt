Zoltán, itt a teljes, részletes, pontonként végrehajtható implementációs
terv, amely végigvezet a toldás‑metaadat, toldás‑finomítás,
PieceBuilder‑integráció, és a vágási terv/címke megjelenítés teljes
beépítésén.

Ez nem kód — ez lépésről lépésre végrehajtható patch‑terv, pontos
sorrenddel, minden érintett modul megjelölésével.
Ahol további részleteket szeretnél, ott Guided Linkeket tettem, hogy
azonnal tudjunk mélyebbre menni.

------------------------------------------------------------------------

I. Toldás metaadat bevezetése (SpliceInfo)

1. Új struct létrehozása

Fájl: model/cutting/piece/spliceinfo.h

    struct SpliceInfo {
        enum class PartType { Main, Addon };

        QUuid groupId;       // requestId vagy külön UUID
        PartType type;       // Main / Addon
        int partIndex;       // 1 vagy 2
        int totalParts = 2;  // fix 2, később bővíthető
    };

------------------------------------------------------------------------

2. PieceWithMaterial bővítése

Fájl: model/cutting/piece/piecewithmaterial.h

Új mező:

    std::optional<SpliceInfo> splice;

Getterek:

    bool isSplice() const { return splice.has_value(); }
    bool isSpliceMain() const { return splice && splice->type == SpliceInfo::PartType::Main; }
    bool isSpliceAddon() const { return splice && splice->type == SpliceInfo::PartType::Addon; }
    int spliceIndex() const { return splice ? splice->partIndex : 0; }
    int spliceGroup() const { return splice ? splice->groupId : QUuid(); }
    int spliceTotal() const { return splice ? splice->totalParts : 0; }

------------------------------------------------------------------------

II. Toldás finomítások beépítése

3. Hulló tolerancia (10 cm)

Fájl: piecebuilder_toldas.h

    const int HULLO_TOLERANCE_MM = 100;

Hulló + hulló és stock + hulló esetén:

    if (combined >= need - HULLO_TOLERANCE_MM) {
        // elfogadjuk, nem kell nagyobb darabot vágni
    }

9. Darab-sorszámozás visszaépítése

A PieceBuilder-ben:

    QString externalRef;
    if (req.quantity > 1) {
        externalRef = QString("%1 %2/%3")
            .arg(req.externalReference)
            .arg(i + 1)
            .arg(req.quantity);
    } else {
        externalRef = req.externalReference;
    }

Majd:

VII. Audit és leftover lifecycle kompatibilitás

13. Toldott darabok auditálása

Az audit modulban:

-   ha piece.isSpliceMain() → fő darab
-   ha piece.isSpliceAddon() → toldó darab

14. Toldott darabok leftover kezelése

Semmit nem kell módosítani:
a leftover lifecycle automatikusan kezeli a darabokat.
