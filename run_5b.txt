Abszolút. Most már van elég információnk ahhoz, hogy ne ötleteljünk, hanem végigverhető tervet rakjunk össze.

A cél:

enum class WorkSheetPresence


esetén automatikusan működjön:

WorkSheetPresence
    ↔ QString


a Meta rendszerben.

És ne kelljen külön serializer-hardcode.

1. lépés - ismerje fel a Meta az enumot

metadata.h

először add hozzá:

#include <type_traits>


majd az AddField()-be:

if constexpr(std::is_enum_v<FieldType>)
{
    zInfo(
        QString("enum=")
        + QString(typeid(FieldType).name()));
}


Várható log:

enum=17WorkSheetPresence
enum=12SizeCalcMode
enum=10NamedColor
enum=11SurfaceType


Ha ez megvan:

✅ enum felismerés kész

2. lépés - EnumTraits bevezetése

Új fájl:

enumtraits.h

#pragma once

template<typename T>
struct EnumTraits;


Semmi más.

3. lépés - 1 enum kipróbálása

Mondjuk:

WorkSheetPresence


specializáció:

template<>
struct EnumTraits<WorkSheetPresence>
{
    static QString ToString(
        WorkSheetPresence v)
    {
        return ::ToString(v);
    }

    static WorkSheetPresence Parse(
        const QString& s)
    {
        return ::ParseWorkSheetPresence(s);
    }
};


A te meglévő függvényeidet kell hívni.

4. lépés - Qt konverter regisztráció

Új helper:

template<typename EnumType>
void RegisterEnumConverters()
{
    static bool done = false;

    if(done)
        return;

    done = true;

    QMetaType::registerConverter<
        EnumType,
        QString>(
        EnumType v
        {
            return EnumTraits<
                EnumType>::ToString(v);
        });

    QMetaType::registerConverter<
        QString,
        EnumType>(
        const QString& s
        {
            return EnumTraits<
                EnumType>::Parse(s);
        });
}

5. lépés - AddField bekötés

A meglévő:

if constexpr(std::is_enum_v<FieldType>)
{
    ...
}


blokk legyen:

if constexpr(std::is_enum_v<FieldType>)
{
    RegisterEnumConverters<
        FieldType>();
}

6. lépés - log ellenőrzés

A mostani:

7. lépés - QVariant ellenőrzés

A mostani:

presence -> valid=0


helyett valami:

presence -> QString valid=1


vagy

presence -> WorkSheetPresence valid=1


attól függően, hogyan kezeli a Qt.

8. lépés - formatter

Ha a QVariant már valid:

A formatterben:

if(value.metaType().id() ==
   QMetaType::QString)
{
    return value.toString();
}


nagy valószínűséggel már elegendő lesz.

Megállási pont

Ha idáig eljutsz és a logban ez látszik:

ENUM WorkSheetPresence cc=1


akkor megállunk.

Nem írunk még enum accessort.

Nem bonyolítjuk túl.

Előbb nézzük meg, hogy a Qt konverter-regisztráció önmagában megoldja-e a problémát.
