1. lépés - fájl parser

Első körben még NEM építünk objektumot.

Csak olvassuk ki a fájlt.

Bemenet:

#SCHEMA

...

#DATA

...


Kimenet:

struct ImportRecord
{
    QMap<QString, QString> values;
};


példa:

{
    "externalReference" : "2815",
    "ownerName" : "Bor M.",
    "productTypeId" : "ROL",
    "calcMode" : "Gyartasi"
}


Kell:

RbCsvImportParser


ami visszaad:

struct ImportDocument
{
    ImportSchema schema;

    QVector<ImportRecord> records;
};

2. lépés - schema reprezentáció

A schema-t objektummá kell alakítani.

Például:

struct ImportField
{
    QString name;
};


Szekció:

struct ImportSection
{
    QString name;

    QVector<ImportField> fields;

    QVector<ImportSection> children;
};


A teljes séma:

struct ImportSchema
{
    ImportSection root;
};


Ugyanaz a fa lesz, mint:

RbCsvExportPlan


csak fájlból építve.

3. lépés - schema migráció

Feladat:

régi mezőnév
      ↓
aktuális mezőnév


Példa:

subtype


↓

productSubtypeCode


Kell:

class SchemaMigrationRegistry
{
};


Egy elem:

struct FieldRename
{
    QString oldField;
    QString newField;
};


példa:

{
    "subtype",
    "productSubtypeCode"
}


Feladat:

ImportRecord


átalakítása:

{
    "subtype" : "TSIN"
}


↓

{
    "productSubtypeCode" : "TSIN"
}

4. lépés - érték migráció

Ez teljesen külön probléma.

Nem a mező neve változott.

Hanem a tartalma.

Példa:

régi:

surface=1


mai:

surface=SM


vagy:

régi:

handlerSide=Left


mai:

leftCount=1
rightCount=0


Ez már:

field+value


szintű migráció.

Kell:

class ValueMigrationRegistry
{
};


Interface:

class IValueMigration
{
public:

    virtual void Migrate(
        ImportRecord& record) const = 0;
};


Példák:

SurfaceMigration_V1

HandlerSideMigration_V1

SubtypeMigration_V2


Ezek ugyanazt a szerepet veszik át, mint ma:

convertRowToCuttingRequestRow_V1()


csak sokkal kisebb granulációban.

5. lépés - MetaField lookup

Amikor már minden migráció lefutott:

ImportRecord


↓

MetaField


keresés.

Példa:

productSubtypeCode


↓

MetaField*


Ehhez kell:

MetaFieldLookup


vagy csak egy helper.

6. lépés - TypeCsvBinding::FromCsv

Meglévő infrastruktúra.

Most export:

Value
   ↓
ToCsv()


Import:

Csv
   ↓
FromCsv()


Példa:

ROL


↓

QUuid

SM


↓

SurfaceType::Smooth

Present


↓

WorkSheetPresence::Present


Ehhez már megvannak a binderek.

7. lépés - MetaValue építés

Eredmény:

QList<MetaValue>


példa:

MetaValue(
    "requiredSurface",
    SurfaceType::Smooth);

MetaValue(
    "productTypeId",
    uuid);

8. lépés - modell építés

Meglévő infrastruktúra:

Meta<T>::FromMetaValues(...)


Példa:

auto summary =
    WorkSheetSummary::Meta()
        .FromMetaValues(values);

10. lépés - verziókezelés filozófiája

NEM lesz:

{
    V1,
    V2,
    ...
}


NEM lesz:

...

ValueMigration
