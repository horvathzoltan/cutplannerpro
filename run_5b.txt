Abszolút. És szerintem most kifejezetten fontos, hogy ne találjunk ki új rendszert, hanem a jelenlegi Meta rendszerből vezessük le a következő réteget.

A jelenlegi állapot:

MetaData
    ↓
MetaField
    ↓
itemType
    ↓
MetaRegistry


már teljesen elegendő a hierarchia bejárásához.

Nem kell:

SchemaNode
MetaComposition
MetaVisitorBase
AbstractWorker


és hasonló új rétegek.

1. lépés - MetaWalker létrehozása

Új fájl:

meta/metawalker.h


Cél:

A jelenlegi

DumpMetaTree(...)


bejárási logikáját kiemelni egy általános függvénybe.

A walker feladata:

- típus belépés
- mező
- composition belépés
- típus kilépés


események meghívása.

Javasolt függvény:

template<typename Worker>
void WalkMetaTree(
    IMetaData* meta,
    Worker& worker,
    int depth = 0)

2. lépés - Worker interfész kialakítása

Nem absztrakt osztály.

Nem virtual.

Csak konvenció.

A walker ezt várja:

worker.EnterType(...)
worker.Field(...)
worker.EnterComposition(...)
worker.LeaveType(...)


Minimális worker API:

void EnterType(
    IMetaData* meta,
    int depth);

void Field(
    IMetaData* meta,
    const MetaFieldBase& field,
    int depth);

void EnterComposition(
    IMetaData* parent,
    const MetaFieldBase& field,
    IMetaData* child,
    int depth);

void LeaveType(
    IMetaData* meta,
    int depth);

3. lépés - DumpMetaTree átírása workerre

Új fájl:

meta/workers/metadumpworker.h


Tartalmazza:

class MetaDumpWorker
{
    ...
};


A régi:

DumpMetaTree(...)


helyett:

inline void DumpMetaTree(IMetaData* meta)
{
    MetaDumpWorker worker;

    WalkMetaTree(
        meta,
        worker);
}


Elvárt kimenet:

ugyanaz marad:

WorkSheetSummary
  orders
    WorkSheetOrderInfo
      materials
        WorkSheetMaterialInfo

4. lépés - Teszt stabilizálása

A jelenlegi teszt marad.

A cél:

Ugyanaz a log.

Semmi funkcionális változás.

Hanem épít:

QString _text;

6. lépés - RBCSV Schema Writer Worker

Új fájl:

rbcsv/rbcsvschemawriterworker.h


Ez ugyanazt a WalkMetaTree-t használja.

Kimenete valami ilyesmi:

$SCHEMA

TYPE=WorkSheetSummary

filePath
fileName
fileHash
presence

SECTION=orders
TYPE=WorkSheetOrderInfo

...

SECTION=materials
TYPE=WorkSheetMaterialInfo

...


A pontos formátum ráér.

8. lépés - Reader

Csak ezután.
