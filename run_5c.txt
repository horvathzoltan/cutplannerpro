4. lépés

Schema beolvasása

Fontos változás az eredeti tervhez képest.

A schema nem külön típus lesz.

Hanem ugyanaz:

RbCsvImportNode


Például:

filePath;fileName;fileHash;presence;orders;[orders]

orders

externalReference;ownerName;...


↓

schema
{
    root
    └─ orders
        └─ materials
}


A mezőnevek bekerülnek:

RbCsvImportRecord::values


alá.

Például:

{
    "0" : "filePath",
    "1" : "fileName",
    ...
}


vagy valamilyen hasonló belső reprezentációval.

Még nem migrálunk.

Még nem típusosítunk.

5. lépés

Data parser

Nagyon fontos változás.

A data parser már a schema alapján dolgozik.

Korábban:

QStringList


ötlet volt.

Most:

QMap<QString,QString>


rögtön.

Példa:

Schema:

externalReference
ownerName
quantity


Adat:

2826;Generálkiv., Pécs;1


↓

{
    "externalReference" : "2826",
    "ownerName" : "Generálkiv., Pécs",
    "quantity" : "1"
}


Ez szerintem hatalmas nyereség.
