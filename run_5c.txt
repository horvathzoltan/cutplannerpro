2. Mérföldkő: Objektum létrehozás a materializerben
Cél

A materializer maga készítse a példányt.

Most:

T object;
Materialize(node,object);


Cél:

T object =
    Materialize<T>(node);

Patch A1

Új overload:

template<typename T>
T Materialize(
    const RbCsvImportNode& node)
{
    T object;

    Materialize(
        node,
        object);

    return object;
}

Elvárt teszt
auto material =
    Materialize<
        WorkSheetMaterialInfo>(
        materialNode);

Eredmény
✅ első truly self-materializing API
