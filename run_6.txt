# PATCH TERV
## 🎯 Cél
1. **Ha találunk hullót → azt *kötelezően* felhasználni**, nem szabad új rúdból kivágni a hulló méretét.
2. **MAIN darabok száma = tétel darabszáma**, nem csak 1.
3. **Hulló felhasználása esetén minden darabhoz külön hulló-keresés** (nem reuse egyetlen hullót több darabra).
4. **Ha hulló van → toldás nem kell** (vagy csak akkor kell, ha a hulló rövidebb a kért darabnál).
5. **Ha hulló nincs → rendes main + toldás workflow indul.**

# 1. PATCH – Hullókezelés új szabályai
### 🔧 1.1. Új enum: `LeftoverUseMode`
```cpp
enum class LeftoverUseMode {
    None,           // nincs hulló
    ExactMatch,     // hulló pontosan jó → main = hulló
    PartialMatch    // hulló rövidebb → hulló + toldás
};
```

### 🔧 1.2. Hulló keresés módosítása
A jelenlegi kód:

```cpp
auto leftover = leftoverRepo.findReusable(materialId, needLength);
```

**PATCH:**

```cpp
auto leftover = leftoverRepo.findReusable(materialId, needLength);
LeftoverUseMode mode = LeftoverUseMode::None;

if (leftover) {
    if (leftover->length == needLength) {
        mode = LeftoverUseMode::ExactMatch;
    } else if (leftover->length < needLength) {
        mode = LeftoverUseMode::PartialMatch;
    }
}
```

# 3. PATCH – Hulló felhasználása MAIN helyett
### 🔧 3.1. ExactMatch esetén
```cpp
if (mode == LeftoverUseMode::ExactMatch) {
    pieces.push_back(PieceWithMaterial::fromLeftover(leftover));
    leftoverRepo.consume(leftover);
    return pieces;
}
```

### 🔧 3.2. PartialMatch esetén
```cpp
if (mode == LeftoverUseMode::PartialMatch) {
    auto base = PieceWithMaterial::fromLeftover(leftover);
    leftoverRepo.consume(leftover);

    int needToldas = needLength - leftover->length;
    auto toldas = buildToldasPiece(materialId, needToldas);

    pieces.push_back(merge(base, toldas));
    return pieces;
}
```

# 5. PATCH – Hulló felhasználása minden darabhoz külön
### 🔧 5.1. A jelenlegi hibás logika
A rendszer:

- talál egy hullót
- de a request.count > 1 esetén **nem keres új hullót a második darabra**

PATCH:

```cpp
for (int i = 0; i < request.count; ++i) {
    auto leftover = leftoverRepo.findReusable(materialId, needLength);
    auto mode = classify(leftover, needLength);
    pieces.push_back(buildPiece(request, leftover, mode));
}
```
